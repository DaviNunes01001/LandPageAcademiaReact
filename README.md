# Academia — Projeto React

Projeto de uma aplicação web para uma academia, desenvolvido em React.

## Status

**Em andamento**

## Paleta de cores

* Preto: `#0B0B0B`
* Cinza: `#171717`
* Vermelho: `#DC2626`
* Branco: `#F5F5F5`

## Tecnologias

* React
* Vite
* JavaScript
* Tailwind CSS
* React Icons
* Zod

## Objetivo

Criar uma interface moderna e responsiva para uma academia, com navegação, componentes reutilizáveis, formulário e interações.

## Funcionalidades

* Página inicial
* Navegação entre páginas
* Planos da academia
* Formulário de contato/cadastro
* Validação com Zod
* Layout responsivo
* Componentes reutilizáveis

## Estrutura

```text
src/
├── components/
├── pages/
├── App.jsx
├── main.jsx
└── index.css
```

## Como executar

```bash
npm install
npm run dev
```
